# Curso Fullstack · Treina Recife

Código das aulas do Curso Fullstack, do professor Izaquiel Queiroz.
Cada pasta traz o projeto de uma aula, do jeito que ficou no fim dela.

Slides, exercícios e o passo a passo de instalação estão no site do curso: <https://treina-16.izaquielqueiroz.dev>

## Como baixar

```bash
git clone https://github.com/keiroez/treina-recife-turma-16.git
```

A cada aula nova, entre na pasta e rode `git pull`.
Para fazer os exercícios, trabalhe numa cópia da pasta da aula: assim o `git pull` não encontra conflito.
